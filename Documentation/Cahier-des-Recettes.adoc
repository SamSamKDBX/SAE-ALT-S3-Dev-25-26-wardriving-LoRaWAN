== Contexte général

=== Présentation du projet

**Client** : Rémi Boulle

**Contexte** : Projet de wardriving LoRaWAN pour cartographier la couverture réseau LoRaWAN de l'IUT de Blagnac.

**Nécessité du projet** : Dans le cadre du développement de l'infrastructure LoRaWAN de l'IUT, il est nécessaire de pouvoir évaluer et visualiser la qualité de la couverture réseau dans différentes zones du campus. Le wardriving permet d'identifier les zones de bonne et mauvaise couverture pour optimiser le positionnement des passerelles LoRaWAN.

**Objectif du projet** : L'objectif de ce projet est de développer une solution de wardriving LoRaWAN à l'aide d'un M5Stack équipé d'un module GPS et LoRaWAN. Le système doit permettre de collecter et transmettre les données de position GPS et de qualité de signal pour une analyse et visualisation sur une carte web interactive.

=== User Stories implémentées

Les User Stories suivantes ont été implémentées :

**US1 - Position GPS** : En tant que client, je souhaite connaître mon emplacement GPS actuel, afin de pouvoir associer la qualité du signal LoRaWAN à une position géographique précise.

**US2 - Qualité du signal** : En tant que client, je souhaite connaître la qualité du signal LoRaWAN à mon emplacement actuel, afin de pouvoir évaluer si la couverture réseau est suffisante à cet endroit.

**US3 - Carte interactive** : En tant que client, je souhaite visualiser sur une carte web interactive la qualité du signal LoRaWAN des emplacements que j'ai parcourus, afin d'analyser la couverture du réseau LoRaWAN sur l'IUT et ses environs.

== Introduction

Ce document a pour but de décrire les tests réalisés sur le système de wardriving LoRaWAN. Vous trouverez ci-dessous chacun des tests réalisés et chacun des résultats observés.

Le cahier de recettes inclut :

- Les tests fonctionnels des User Stories
- Les tests d'interface (affichage écran LCD et interface web)
- Les tests de communication (GPS, LoRaWAN et MQTT)
- La description des tests unitaires et d'intégration
- La couverture et la pertinence des tests

== Prérequis

Pour réaliser ces tests, il faut :

- Avoir accès au dépôt GitHub du projet
- Disposer d'un M5Stack Core avec module LoRaWAN (Ra-01H) et GPS (NEO-M8N)
- Être en extérieur avec vue dégagée du ciel (pour les tests GPS)
- Avoir accès au réseau LoRaWAN de l'IUT
- Un ordinateur avec Docker et Docker Compose installés
- Un navigateur web moderne (Chrome, Firefox, Edge)
- Un ordinateur avec PlatformIO et moniteur série (pour les tests détaillés M5Stack)
