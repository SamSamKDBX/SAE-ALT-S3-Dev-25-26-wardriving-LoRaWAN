== Introduction

=== Objectif du document

Ce document décrit les procédures d'installation et de configuration du système de wardriving LoRaWAN. Il est destiné aux administrateurs informatiques chargés de déployer l'application sur les postes de travail.

=== Présentation du système

Le système de wardriving LoRaWAN permet de cartographier la couverture du réseau LoRaWAN en collectant des données GPS et de qualité de signal (SNR/RSSI). Il est composé de :

* **Un M5Stack Core** équipé d'un module GPS et LoRaWAN qui collecte et transmet les données
* **Une application Docker** qui reçoit les données via MQTT et les affiche sur une carte web interactive

=== Architecture technique

[source]
----

|  M5Stack    | --------------> |  Passerelle      | -------------> |  Broker MQTT     |
|  Core + GPS |     868 MHz     |  LoRaWAN IUT     |                |  ChirpStack      |
+-------------+                 +------------------+                +------------------+
                                                                            |

                                                                   |  - Collecteur    |
                                                                   |  - Serveur Web   |
                                                                   +------------------+
                                                                            |
                                                                            v
                                                                   +------------------+
                                                                   |  Navigateur Web  |
                                                                   |  localhost:8080  |
                                                                   +------------------+
----

== Configuration du M5Stack

=== Modification du fichier config.h

Ouvrez le fichier `Code-M5Stack/config.h` et modifiez les valeurs selon votre configuration.

==== Cas 1 : Installation à l'IUT de Blagnac

Si vous êtes à l'IUT de Blagnac, modifiez uniquement l'identifiant du M5Stack :

[source,cpp]
----
#ifndef CONFIG_H
#define CONFIG_H

// Modifier cette valeur selon le M5Stack utilisé (ex: 0x06, 0x07, 0x1C, etc.)
#define M5STACK_ID 0x1C

// Ces valeurs sont pré-configurées pour l'IUT de Blagnac
#define LORAWAN_DEVEUI {0x06, 0x01, 0x03, 0x02, 0x01, 0x45, 0x7E, 0x0C}
#define LORAWAN_APPKEY {0x01, 0x02, 0x03, 0x04, 0x05, 0x06, 0x07, 0x08, 0x09, 0x0A, 0x0B, 0x0C, 0x0D, 0x0E, 0x01, 0x06}

#endif
----

[NOTE]
====
Le `M5STACK_ID` doit correspondre au dernier octet du DevEUI de votre device sur ChirpStack.
====

==== Cas 2 : Installation dans un autre établissement

Si vous êtes dans un autre établissement, vous devez configurer les identifiants LoRaWAN selon votre infrastructure :

[source,cpp]
----
#ifndef CONFIG_H
#define CONFIG_H

// Identifiant unique de votre M5Stack
#define M5STACK_ID 0xXX

// DevEUI de votre device (format little-endian, octets inversés)
// Exemple : si DevEUI = 0C7E450102030106, écrire {0x06, 0x01, 0x03, 0x02, 0x01, 0x45, 0x7E, 0x0C}
#define LORAWAN_DEVEUI {0xXX, 0xXX, 0xXX, 0xXX, 0xXX, 0xXX, 0xXX, 0xXX}

// AppKey de votre application LoRaWAN (format big-endian, ordre normal)
#define LORAWAN_APPKEY {0xXX, 0xXX, 0xXX, 0xXX, 0xXX, 0xXX, 0xXX, 0xXX, 0xXX, 0xXX, 0xXX, 0xXX, 0xXX, 0xXX, 0xXX, 0xXX}

#endif
----

[IMPORTANT]
====
Les valeurs DevEUI et AppKey doivent correspondre à celles configurées sur votre serveur LoRaWAN (ChirpStack, TTN, etc.).
====

== Configuration de l'environnement Docker

=== Modification du fichier .env

Le fichier `.env` à la racine du projet contient la configuration du collecteur MQTT.

==== Cas 1 : Installation à l'IUT de Blagnac

**Si l'ordinateur est connecté en filaire au réseau de l'IUT** :

[source,bash]
----
# Connexion MQTT
MQTT_BROKER=chirpstack.iut-blagnac.fr
MQTT_PORT=1883
MQTT_USERNAME=
MQTT_PASSWORD=
MQTT_USE_TLS=false

# Identification du device (doit correspondre au DevEUI complet)
DEVEUI=0c7e450102030106

# Application ChirpStack
CHIRPSTACK_APP_ID=6
----

**Si l'ordinateur est connecté en WiFi ou depuis l'extérieur** :

[source,bash]
----
# Connexion MQTT sécurisée
MQTT_BROKER=chirpstack.iut-blagnac.fr
MQTT_PORT=8883
MQTT_USERNAME=
MQTT_PASSWORD=
MQTT_USE_TLS=true

# Identification du device
DEVEUI=0c7e450102030106

# Application ChirpStack
CHIRPSTACK_APP_ID=6
----

==== Cas 2 : Installation dans un autre établissement

Adaptez les paramètres selon votre infrastructure MQTT :

[source,bash]
----
# Connexion MQTT
MQTT_BROKER=votre-broker-mqtt.fr
MQTT_PORT=8883
MQTT_USERNAME=votre_utilisateur
MQTT_PASSWORD=votre_mot_de_passe
MQTT_USE_TLS=true

# Identification du device
DEVEUI=votre_deveui_complet

# Application (adapter selon votre serveur LoRaWAN)
CHIRPSTACK_APP_ID=votre_app_id
----

[cols="1,3", options="header"]
|===
| Paramètre | Description

| MQTT_BROKER
| Adresse du broker MQTT de votre serveur LoRaWAN

| MQTT_PORT
| Port MQTT (généralement 1883 sans TLS, 8883 avec TLS)

| MQTT_USERNAME
| Nom d'utilisateur MQTT (laisser vide si pas d'authentification)

| MQTT_PASSWORD
| Mot de passe MQTT (laisser vide si pas d'authentification)

| MQTT_USE_TLS
| Activer le chiffrement TLS (true/false)

| DEVEUI
| DevEUI complet du device en hexadécimal (16 caractères)

| CHIRPSTACK_APP_ID
| Identifiant de l'application sur le serveur LoRaWAN
|===

== Téléversement du programme sur le M5Stack

=== Procédure de téléversement

1. Connectez le M5Stack à l'ordinateur via un câble USB-C
2. Ouvrez le dossier `Code-M5Stack` dans Visual Studio Code
3. PlatformIO détectera automatiquement le projet
4. Cliquez sur l'icône PlatformIO dans la barre latérale gauche
5. Dans le menu "PROJECT TASKS", cliquez sur **"Upload"**
6. Attendez la fin de la compilation et du téléversement

IMAGE IMAGE IMAGE

[NOTE]
====
Le premier téléversement peut prendre plusieurs minutes car PlatformIO doit télécharger les dépendances (M5Unified, TinyGPSPlus, LMIC).
====

=== Vérification du téléversement

Après le téléversement, le M5Stack redémarre automatiquement et affiche :

----
Starting...
Recherche GPS...

Verifiez:
- Antenne branchee
- Etre dehors
- Attendre 1-2 min
----

Pour observer les logs détaillés, ouvrez le moniteur série dans PlatformIO (icône prise électrique ou "Monitor" dans PROJECT TASKS). Le débit est configuré à 115200 bauds.

== Déploiement de l'application Docker

Depuis la racine du projet, exécutez :

=== Résolution des problèmes courants

[cols="1,2,2", options="header"]
|===
| Problème | Cause probable | Solution

| M5Stack affiche "SIGNAL PERDU !"
| Pas de signal GPS
| Se placer en extérieur avec vue dégagée du ciel

| Docker : "Échec de connexion"
| Mauvaise configuration MQTT
| Vérifier MQTT_BROKER, MQTT_PORT et MQTT_USE_TLS dans .env

| Pas de données reçues
| DevEUI incorrect
| Vérifier que le DEVEUI dans .env correspond au config.h

| Carte vide après 5 min
| M5Stack non connecté au réseau LoRaWAN
| Vérifier les logs série du M5Stack (EV_JOINED doit apparaître)
|===

== Arrêt et maintenance

=== Arrêt de l'application

Pour arrêter l'application Docker :

* Appuyez sur **Ctrl+C** dans le terminal
* Ou exécutez : `docker compose down`

=== Relancement pour les utilisateurs

Une fois l'installation effectuée, les utilisateurs peuvent relancer l'application avec :

[source,bash]
----
docker compose up
----

[NOTE]
====
La commande `--build` n'est plus nécessaire après la première installation, sauf en cas de modification du code source.
====

=== Mise à jour du projet

Pour mettre à jour le projet vers une nouvelle version :

[source,bash]
----
git pull origin main
docker compose up --build
----
