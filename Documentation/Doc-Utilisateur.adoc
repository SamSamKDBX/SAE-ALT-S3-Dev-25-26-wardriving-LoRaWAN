== Introduction

=== Qu'est-ce que le Wardriving LoRaWAN ?

Le wardriving LoRaWAN est une technique qui consiste à se déplacer dans une zone géographique pour cartographier la qualité de couverture d'un réseau LoRaWAN.

Cette application vous permet de :

* **Visualiser votre position GPS** en temps réel sur l'écran du M5Stack
* **Mesurer la qualité du signal** LoRaWAN à chaque emplacement
* **Afficher une carte interactive** montrant les zones de bonne et mauvaise couverture

=== À qui s'adresse ce document ?

Ce document est destiné aux utilisateurs finaux qui souhaitent effectuer des sessions de wardriving. L'installation technique a déjà été réalisée par un administrateur.

[NOTE]
====
Si l'application n'est pas encore installée sur votre poste, veuillez contacter votre administrateur ou consulter le Document Administrateur.
====

== Matériel à disposition

Pour effectuer une session de wardriving, vous disposez de :

* **Un M5Stack Core** : boîtier noir avec écran couleur
* **Un ordinateur** : avec l'application déjà configurée

[IMPORTANT]
====
Le M5Stack est déjà programmé et prêt à l'emploi. Vous n'avez pas besoin de le configurer.
====

== Démarrage de l'application

=== Étape 1 : Allumer le M5Stack

Appuyez sur le bouton d'alimentation situé sur le côté gauche du M5Stack.

L'écran affiche au démarrage :

----
Starting...
Recherche GPS...

Verifiez:
- Antenne branchee
- Etre dehors
- Attendre 1-2 min
----

[TIP]
====
Le M5Stack fonctionne sur batterie. Si la batterie est faible, connectez-le à une source d'alimentation USB.
====

=== Étape 2 : Lancer l'application sur l'ordinateur

1. Ouvrez un **terminal** (ou invite de commandes)
2. Naviguez vers le dossier du projet :
+
[source,bash]
----
cd SAE-ALT-S3-Dev-25-26-wardriving-LoRaWAN
----

3. Lancez l'application :
+
[source,bash]
----
docker compose up
----

4. Attendez que le message suivant apparaisse :
+
----
Connecté au broker MQTT
----

=== Étape 3 : Ouvrir la carte web

1. Ouvrez votre **navigateur web** (Chrome, Firefox, Edge...)
2. Accédez à l'adresse : **http://localhost:8080**

La page affiche un message d'attente :

----
En attente de données...
La carte se centrera sur les premières coordonnées GPS reçues.
----

=== Étape 4 : Attendre la connexion

La connexion complète du système peut prendre **jusqu'à 5 minutes**. Voici ce qui se passe :

1. Le M5Stack recherche les satellites GPS
2. Le M5Stack se connecte au réseau LoRaWAN
3. Les premières données sont transmises
4. La carte se centre automatiquement sur votre position

[IMPORTANT]
====
Placez-vous **en extérieur** avec une vue dégagée du ciel pour une acquisition GPS rapide.
====

Lorsque le GPS est acquis, l'écran du M5Stack affiche :

----
=== MA POSITION ===

Latitude: 43.648567
Longitude: 1.373426
Satellites: 8
----

Et la carte web se met à jour avec les premières cellules colorées.

== Utilisation de la carte web

=== Présentation de l'interface

[width=50%]
image::screenshot-webview-iut.png[Carte]

L'interface web comprend :

[cols="1,3", options="header"]
|===
| Élément | Description

| Carte
| Affiche les cellules colorées représentant la qualité du signal

| Panneau d'information (en haut à droite)
| Affiche les statistiques en temps réel

| Légende (en bas à droite)
| Explique le code couleur des cellules
|===

=== Comprendre les couleurs

La carte affiche des cellules de 10m × 10m colorées selon la qualité du signal :

[cols="1,2,3", options="header"]
|===
| Couleur | Qualité | Signification

| Vert
| Excellent (SNR > 10 dB)
| Très bonne couverture, signal fort

| Jaune
| Bon (SNR 0 à 10 dB)
| Bonne couverture, signal correct

| Orange
| Moyen (SNR -10 à 0 dB)
| Couverture acceptable, signal faible

| Rouge
| Faible (SNR < -10 dB)
| Mauvaise couverture, signal très faible
|===

=== Panneau d'information

Le panneau en haut à droite affiche :

* **Points collectés** : nombre total de mesures effectuées
* **Cellules couvertes** : nombre de zones cartographiées
* **Dernière MAJ** : heure de la dernière mise à jour
* **SNR actuel** : qualité du signal de la dernière mesure
* **RSSI** : puissance du signal reçu

=== Interagir avec la carte

* **Zoom** : utilisez la molette de la souris ou les boutons +/-
* **Déplacement** : cliquez et faites glisser la carte
* **Détails d'une cellule** : cliquez sur une cellule colorée pour voir ses informations

== Effectuer une session de wardriving

=== Préparation

Avant de partir :

1. Vérifiez que le M5Stack est chargé
2. Lancez l'application sur l'ordinateur
3. Attendez que la connexion soit établie
4. Planifiez votre itinéraire

=== Pendant le déplacement

1. **Emportez le M5Stack** avec vous pendant vos déplacements
2. L'écran du M5Stack continue d'afficher votre position
3. Les données sont transmises **automatiquement** toutes les 10 secondes
4. La carte web se met à jour en temps réel sur l'ordinateur

[TIP]
====
Marchez à vitesse normale. Le système capture une mesure tous les 10 mètres environ.
====

=== Conseils pour une bonne cartographie

* **Restez en extérieur** pour maintenir le signal GPS
* **Variez les zones** : testez différents endroits du campus
* **Observez les changements de couleur** pour identifier les zones de mauvaise couverture
* **Évitez de rester immobile trop longtemps** : plusieurs mesures au même endroit écrasent les précédentes

== Écrans du M5Stack

=== Écran de position GPS

Cet écran s'affiche lorsque le GPS fonctionne correctement :

----
=== MA POSITION ===

Latitude: 43.648567
Longitude: 1.373426
Satellites: 8
----

* **Latitude/Longitude** : vos coordonnées GPS actuelles
* **Satellites** : nombre de satellites GPS captés (plus c'est élevé, mieux c'est)

=== Écran de perte de signal

Si le signal GPS est perdu pendant plus de 10 secondes :

----
SIGNAL PERDU !

Depuis : 15 sec

Verifiez:
- Antenne GPS
- Etre dehors
- Vue du ciel
----

**Que faire ?**

1. Déplacez-vous vers une zone plus dégagée
2. Vérifiez que l'antenne GPS est bien connectée
3. Attendez quelques secondes que le signal revienne

[NOTE]
====
Le signal GPS peut être temporairement perdu sous les arbres, près des bâtiments ou en intérieur. Cela n'affecte pas les données déjà collectées.
====

== Arrêt de l'application

=== Arrêter l'application sur l'ordinateur

1. Retournez dans le terminal où l'application est lancée
2. Appuyez sur **Ctrl+C**
3. L'application s'arrête

=== Éteindre le M5Stack

Maintenez le bouton d'alimentation enfoncé pendant 2 secondes.

[TIP]
====
Les données collectées pendant la session sont conservées. Elles seront de nouveau visibles au prochain lancement.
====

== Résolution des problèmes

=== Le M5Stack affiche "SIGNAL PERDU !"

[cols="1,2", options="header"]
|===
| Cause | Solution

| Vous êtes en intérieur
| Sortez à l'extérieur avec une vue dégagée du ciel

| L'antenne GPS est déconnectée
| Vérifiez que l'antenne est bien vissée sur le M5Stack

| Zone avec obstacles
| Éloignez-vous des bâtiments et des arbres
|===

=== La carte reste vide

[cols="1,2", options="header"]
|===
| Cause | Solution

| Application pas encore connectée
| Attendez jusqu'à 5 minutes que la connexion s'établisse

| M5Stack éteint ou hors de portée
| Vérifiez que le M5Stack est allumé et affiche une position GPS

| Problème de configuration
| Contactez votre administrateur
|===

=== L'application ne démarre pas

[cols="1,2", options="header"]
|===
| Cause | Solution

| Docker n'est pas lancé
| Contactez votre administrateur pour vérifier l'installation

| Mauvais dossier
| Vérifiez que vous êtes dans le dossier du projet avant de lancer la commande
|===

=== Le M5Stack ne s'allume pas

[cols="1,2", options="header"]
|===
| Cause | Solution

| Batterie déchargée
| Connectez le M5Stack à un câble USB pour le recharger

| Bouton mal pressé
| Appuyez fermement sur le bouton d'alimentation pendant 1 seconde
|===

== Glossaire

[cols="1,3", options="header"]
|===
| Terme | Définition

| GPS
| Global Positioning System - système de géolocalisation par satellite

| LoRaWAN
| Long Range Wide Area Network - réseau sans fil longue portée à faible consommation

| SNR
| Signal-to-Noise Ratio - rapport signal sur bruit, mesure de la qualité du signal (en dB)

| RSSI
| Received Signal Strength Indicator - puissance du signal reçu (en dBm)

| Wardriving
| Technique de cartographie des réseaux sans fil en se déplaçant dans une zone

| Cellule
| Zone de 10m × 10m sur la carte représentant une mesure de qualité de signal
|===
