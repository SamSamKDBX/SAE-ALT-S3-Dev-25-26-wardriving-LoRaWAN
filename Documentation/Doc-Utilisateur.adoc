== Introduction

=== Présentation du projet

Le projet Wardriving LoRaWAN consiste à cartographier la couverture du réseau LoRaWAN de l'IUT de Blagnac en se déplaçant dans la zone avec un dispositif M5Stack équipé d'un module GPS et LoRaWAN.

Le système permet de :

- Connaître sa position GPS actuelle (latitude, longitude, nombre de satellites)
- Mesurer la qualité du signal LoRaWAN à chaque position
- Transmettre ces données pour une visualisation ultérieure sur une carte interactive

=== Objectifs

Cette application permet aux utilisateurs de :

- Visualiser en temps réel leur position GPS sur l'écran du M5Stack
- Collecter des données de couverture LoRaWAN pendant leurs déplacements
- Identifier les zones de bonne et mauvaise couverture réseau

== Matériel nécessaire

=== Équipement requis

Pour utiliser le système de wardriving LoRaWAN, vous aurez besoin de :

- **M5Stack Core** : Dispositif principal avec écran LCD
- **Module LoRaWAN 868MHz** : Pour la communication avec le réseau LoRaWAN
- **Module GPS** : Pour la géolocalisation (connecté sur Serial2, pins RX=16, TX=17)
- **Antenne GPS** : Impérativement connectée au module GPS
- **Antenne LoRaWAN 868MHz** : Pour optimiser la portée du signal
- **Batterie ou alimentation USB** : Pour alimenter le M5Stack pendant les déplacements

=== Vérifications avant utilisation

Avant de démarrer le système, assurez-vous que :

1. Les antennes GPS et LoRaWAN sont correctement branchées
2. Le M5Stack est chargé ou connecté à une source d'alimentation
3. Vous êtes en extérieur avec une vue dégagée du ciel pour le GPS

== Installation et configuration

=== Prérequis logiciels

- PlatformIO ou Arduino IDE
- Bibliothèques nécessaires :
  * M5Unified
  * LMIC (LoRaWAN)
  * TinyGPSPlus

=== Configuration du M5Stack

Avant de téléverser le code sur le M5Stack, vous devez configurer l'identifiant du dispositif :

1. Ouvrez le fichier `config.h`
2. Modifiez la valeur de `M5STACK_ID` selon votre dispositif :

[source,cpp]
----
#define M5STACK_ID 0x1C  // Remplacer par l'ID de votre M5Stack
----

=== Téléversement du programme

1. Connectez le M5Stack à votre ordinateur via USB
2. Ouvrez le projet dans PlatformIO
3. Sélectionnez le bon port COM
4. Cliquez sur "Upload" pour téléverser le programme
5. Le M5Stack redémarrera automatiquement

== Utilisation du système

=== Démarrage

Au démarrage, le M5Stack affiche :

----
Starting...
Recherche GPS...

Verifiez:
- Antenne branchee
- Etre dehors
- Attendre 1-2 min
----

Le système tente de se connecter au réseau LoRaWAN (mode OTAA) et de trouver des satellites GPS.

**IMPORTANT** : La première acquisition GPS peut prendre 1 à 2 minutes en extérieur. Soyez patient.

=== Écran principal - Position GPS

Une fois le signal GPS acquis, l'écran affiche en temps réel :

----
=== MA POSITION ===

Latitude: 43.648567
Longitude: 1.373426
Satellites: 8
----

Les informations se mettent à jour automatiquement dès que le GPS détecte un changement de position.

**Code couleur de l'écran :**

- **Jaune** : Titre de la section
- **Vert** : Labels des informations
- **Blanc** : Valeurs des données

=== Détection de perte de signal GPS

Si le signal GPS est perdu pendant plus de 10 secondes, l'écran affiche :

----
SIGNAL PERDU !

Depuis : XX sec

Verifiez:
- Antenne GPS
- Etre dehors
- Vue du ciel
----

**En cas de perte de signal :**

1. Vérifiez que l'antenne GPS est bien connectée
2. Assurez-vous d'être en extérieur
3. Évitez les zones avec obstacles (bâtiments, arbres denses)
4. Attendez quelques instants que le signal soit retrouvé

=== Transmission des données LoRaWAN

Le M5Stack envoie automatiquement les données GPS via LoRaWAN toutes les 10 secondes.

**Format des données envoyées (JSON) :**

Avec signal GPS valide :
[source,json]
----
{
  "type": "gps",
  "lat": 43.648567,
  "lon": 1.373426,
  "sat": 8,
  "age": 120
}
----

Sans signal GPS :
[source,json]
----
{
  "type": "gps",
  "fix": false
}
----

Les données incluent :

- **lat** : Latitude (6 décimales)
- **lon** : Longitude (6 décimales)
- **sat** : Nombre de satellites captés
- **age** : Âge de la dernière position GPS en millisecondes
- **fix** : Indicateur de présence ou absence de signal GPS

Le SNR (Signal-to-Noise Ratio) et les métadonnées LoRaWAN sont automatiquement ajoutés par le serveur LoRaWAN lors de la réception.

== Conseils d'utilisation pour le wardriving

=== Préparation du parcours

1. Chargez complètement le M5Stack avant de partir
2. Planifiez votre itinéraire pour couvrir les zones d'intérêt
3. Prévoyez d'être en extérieur pendant toute la durée du mapping

=== Pendant le mapping

1. Maintenez le M5Stack en position verticale pour optimiser la réception GPS
2. Déplacez-vous à vitesse de marche normale (pas trop rapide)
3. Surveillez l'écran pour vérifier que le GPS reste actif
4. Les données sont envoyées automatiquement, aucune action n'est requise

=== Zones à privilégier

- **Espaces ouverts** : Pour une bonne réception GPS
- **Différents étages** : Pour tester la couverture verticale
- **Intérieurs/Extérieurs** : Pour comparer la qualité du signal
- **Points éloignés des passerelles** : Pour identifier les limites de couverture

== Messages et indicateurs

=== Messages du moniteur série

Si vous connectez le M5Stack à un ordinateur, vous pouvez suivre l'activité sur le moniteur série (115200 bauds) :

- `EV_JOINING` : Connexion au réseau LoRaWAN en cours
- `EV_JOINED` : Connecté avec succès au réseau LoRaWAN
- `Envoi => {...}` : Données GPS envoyées
- `Packet queued` : Paquet en attente d'envoi
- `EV_TXCOMPLETE` : Transmission terminée
- `Position: XX.XXXXXX, YY.YYYYYY` : Position GPS mise à jour

=== Résolution des problèmes courants

[cols="1,2", options="header"]
|===
| Problème | Solution

| Le GPS ne trouve pas de satellites
| Assurez-vous d'être en extérieur avec une vue dégagée du ciel. Attendez 1-2 minutes. Vérifiez que l'antenne GPS est branchée.

| L'écran affiche "SIGNAL PERDU !"
| Déplacez-vous dans une zone plus ouverte. Vérifiez la connexion de l'antenne GPS.

| Le M5Stack ne démarre pas
| Vérifiez la charge de la batterie. Essayez de connecter le M5Stack via USB.

| Pas de connexion LoRaWAN
| Vérifiez que l'antenne LoRaWAN est connectée. Assurez-vous d'être à portée d'une passerelle LoRaWAN.

| Les données ne s'affichent pas
| Vérifiez les messages sur le moniteur série. Attendez que le M5Stack se connecte au réseau LoRaWAN (EV_JOINED).
|===

== Spécifications techniques

=== Paramètres GPS

- **Débit série** : 9600 bauds
- **Pins** : RX=16, TX=17
- **Timeout** : 10 secondes sans signal
- **Précision** : 6 décimales (environ 10cm)

=== Paramètres LoRaWAN

- **Fréquence** : 868 MHz (EU)
- **Mode** : OTAA (Over-The-Air Activation)
- **Intervalle d'envoi** : 10 secondes
- **Port** : 1
- **Confirmation** : Activée

=== Pins utilisées

[cols="1,2", options="header"]
|===
| Fonction | Pin

| GPS RX | 16
| GPS TX | 17
| LoRa NSS | 5
| LoRa RST | 26
| LoRa DIO0 | 36
| LoRa DIO1 | 35
|===

== Exploitation des données

Les données collectées par le M5Stack sont reçues sur le serveur LoRaWAN via MQTT. Le serveur ajoute automatiquement :

- Le SNR (Signal-to-Noise Ratio)
- L'identifiant de la passerelle qui a reçu le signal
- Le RSSI (Received Signal Strength Indicator)
- L'horodatage de réception

Ces données peuvent ensuite être exploitées pour créer une carte de couverture interactive montrant la qualité du réseau LoRaWAN en fonction de la position géographique.
