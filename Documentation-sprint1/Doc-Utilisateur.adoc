== Introduction

L'application web du wardriving à pour but de pouvoir éffectuer du mapping sur le terrain de l'IUT, on va connnecter le M5 à un réseau internet et il va nous afficher dans une permière partie le nombre de satélite qui on trouvé le M5,
puis dans une deuxième partie le M5 va nous afficher le SNR (la qualité du réseau LoRaWAN)

[[utilisateur]]
== Gérer les utilisateurs

Afin de gérer les utilisateurs sur cette application, dirigez vous vers le menu nommé “Gestion des utilisateurs”. 

Notez qu'il est **nécessaire** d’être connecté pour **accéder** à cette fonctionnalité.


=== Consulter les utilisateurs

Afin de consulter les utilisateurs, rendez-vous d’abord sur la fenêtre de gestion des
utilisateurs <<utilisateur, cf.Gérer les utilisateurs.>>

'''


Une fois sur la fenêtre de gestion des utilisateurs, vous apercevrez la liste des différents
utilisateurs enregistrés.

=== Créer un utilisateur

Afin de créer un utilisateur, rendez-vous d’abord sur la fenêtre de gestion des utilisateurs <<utilisateur, cf.Gérer les utilisateurs.>>

'''


Une fois sur la fenêtre de gestion des utilisateurs, cliquez sur le bouton “Nouvel utilisateur” .

'''


Une fenêtre permettant de créer un nouvel utilisateur apparaît donc, entrez son nom, mot de passe et rôle (obligatoires).


'''


Une fois tous les champs remplis, cliquez sur le bouton “Valider” pour confirmer la création du nouvel utilisateur. 

Cliquez sur “Annuler” pour annuler la création.

'''


Si des informations dans des champs sont manquantes ou bien erronées, un message d’erreur vous informera des modifications à apporter.

'''



Vous pouvez ensuite constater que le nouvel utilisateur créé a été ajouté dans la liste.

=== Modifier un utilisateur

Afin de modifier un utilisateur, rendez-vous d’abord sur la fenêtre de gestion des utilisateurs <<utilisateur, cf.Gérer les utilisateurs.>>

'''



Une fois sur la page de gestion des utilisateurs, sélectionnez l’utilisateur que vous voulez modifier. Cliquez ensuite sur le bouton “Modifier”.

'''


Une fenêtre permettant de modifier l’utilisateur apparaît donc, entrez son nom, mot de
passe et rôle (obligatoires). 

- Cliquez sur “Valider” lorsque tous les champs sont bien remplis afin d’enregistrer les modifications. 

- Cliquez sur “Annuler” pour annuler les modifications.

'''



Si des informations dans des champs sont manquantes ou bien erronées, un message
d’erreur vous informera des modifications à apporter.

=== Supprimer un utilisateur

Afin de supprimer un utilisateur, rendez-vous d’abord sur la fenêtre de gestion des utilisateurs <<utilisateur, cf.Gérer les utilisateurs.>>

'''


Une fois sur la fenêtre de gestion des utilisateurs, sélectionnez l’utilisateur que vous désirez supprimer comme sur l’image ci-dessus.

'''



Cliquez ensuite sur le bouton “Supprimer”.

'''


Une fenêtre de confirmation s’affiche.

- Cliquez sur “OK” pour valider la suppression de l’utilisateur. 

- Cliquez sur “Annuler” pour annuler la suppression.
